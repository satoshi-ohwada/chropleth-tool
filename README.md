# 青森県コロプレスマップ作成ツール

ブラウザ上で完結し、青森県内の市町村別データから色分けマップ（コロプレスマップ）を簡単に作成・エクスポートできるWebアプリケーションです。

## 主な機能

* **簡単なデータ入力**: Excelやスプレッドシートからコピー＆ペースト可能なタブ区切りテキスト（TSV）形式でデータを入力できます。
* **高度なラベル自動配置**: 
  * GeoJSONの形状データから動的に面積が最大のポリゴン（飛び地対応）を判定し、正確な重心を計算してラベルを配置します。
  * 物理演算（Force-directed layout）を用いて、過密地域でもラベル同士の重なりを自動的に回避し、必要に応じて引出線を自動描画します。
* **多彩なカラーパレットと階級分け**: 
  * 単色の濃淡、複数色のグラデーション（Viridis, Magmaなど）、離散色（Set1など）をサポート。
  * **白黒印刷・資料向け**: 白黒出力でも判別しやすい斜線や格子などのハッチング（SVGパターン）にも対応しています。
  * Quantile（等量）、Equal Interval（等間隔）、Jenks（自然分類）、独自の手動設定など、柔軟なしきい値設定が可能です。
* **高画質エクスポート**: 作成した地図はPNG画像として高解像度（倍率指定可能）でダウンロードできます。

## 使い方

このツールはフロントエンド技術（HTML/CSS/JavaScript）のみで構築されていますが、モジュールやデータの読み込み（CORS制約）のため、ローカルWebサーバー経由で起動する必要があります。

### 起動方法

プロジェクトのルートディレクトリで以下のいずれかのコマンドを実行してください。

```bash
# Pythonのビルトインサーバーを使用する場合
./start_server.sh

# または直接Pythonスクリプトを実行
python3 start_server.py
```

サーバーが起動したら、ブラウザで `http://localhost:8000` （またはターミナルに表示されたURL）にアクセスしてください。

## 技術スタック

* **コア**: HTML5, CSS3, JavaScript (Vanilla)
* **地図描画**: [Leaflet.js](https://leafletjs.com/)
* **統計・階級分け**: [geostats](https://github.com/simogeo/geostats)
* **画像エクスポート**: [html-to-image](https://github.com/bubkoo/html-to-image) / html2canvas
* **アイコン**: FontAwesome
* **データ**: 青森県内の市区町村境界 GeoJSON

## 開発・カスタマイズ

* `index.html`: UI構造およびライブラリの読み込み。
* `style.css`: カスタムスタイリング、UIのレイアウト定義。
* `app.js`: アプリケーションのメインロジック（データパース、地図描画、統計処理、ラベルの物理演算など）。
* `data/aomori_municipalities.geojson`: 地図描画のベースとなる青森県の境界データ。
