# 青森県市町村コロプレスツール 利用者マニュアル＆チュートリアル

本ツールは、青森県内全40市町村の各種統計データ（人口、面積、労働、製造業、医療、財政など）から、わかりやすく美しい色分け地図（コロプレスマップ）を直感的に作成・分析・エクスポートできるWebアプリケーションです。

データを外部サーバーへ送信せず、すべてお使いのWebブラウザ内（ローカル環境）で安全に高速処理します。

## 1. 本ツールの特長

* 🔒 **安心のセキュア設計**: データを外部サーバーに送信しない完全クライアントサイド処理。独自の統計データや内部資料も安心して利用可能です。
* 📊 **豊富なプリセットデータ（全100項目以上収録）**: 「R8青森県統計年鑑 市町村データ100」や「統計でみる市区町村のすがた 2026」をワンクリックで読み込み、すぐに可視化できます。
* 📋 **Excel / Web表から直接コピペOK**: 表データをコピー＆ペーストするだけで全自動インポート。市町村名の誤字脱字や「市・町・村」の省略、ひらがな・カタカナも自動で判別補正します。
* 📈 **分布分析 ＆ 自動判別アドバイス**: ヒストグラムとカーネル密度推定（KDE）曲線でデータの偏り（歪度）を可視化。「実測値」「100人あたり(%)」「Zスコア」「Jenks自然分類」など、最適な分析・描画手法を理由付きでアドバイスします。
* 🎨 **多彩なカラー表現 ＆ 白黒印刷対応**: 鮮やかなカラーグラデーションに加え、報告書やモノクロ印刷・資料作成に最適な白黒ハッチングパターン（斜線・格子・点模様）やZスコア専用配色を完備。
* 🖼️ **高解像度PNG保存 ＆ クリップボードコピー**: 作成したコロプレスマップをワンクリックで高精細PNG画像としてダウンロード、またはプレゼン資料へ直接貼り付けコピーできます。

## 2. 動作環境・使い方

本ツールは特別なサーバー構築や複雑なインストール作業を必要としません。

1. **動作環境**: Google Chrome, Microsoft Edge, Safari などのモダンブラウザ
2. **起動方法**:
   - `start_server.sh` を実行するか、`python3 -m http.server 8000` でローカルサーバーを立ち上げてアクセスします。
   - ブラウザで `http://localhost:8000` を開くだけですぐに利用可能です。

## 4. 画面1：データ読み込み ＆ 分布統計分析

### 4-1. データ取り込み（3通りの方法）

分析・作図に使用するデータは以下の3つの方法で読み込めます。縦一列に配置されており、迷わず操作できます。

1. ✨ **プリセットデータを読み込む（ワンクリック）**:
   - **R8青森県統計年鑑 市町村データ100**（面積、人口、就業者、製造業、医療、財政等 全100指標）
   - **統計でみる市区町村のすがた 2026**（e-Stat 主要33社会経済指標）
2. 📁 **方法①：CSV / Excelファイルから直接読み込む**: `.xlsx`, `.csv`, `.tsv` ファイルをドラッグ＆ドロップするかファイル参照で選択します。
3. 📋 **方法②：テキスト一括貼り付け（コピー＆ペースト）**: Excelやスプレッドシート、Webサイトの表をそのままコピーしてテキスト枠に貼り付けます。

### 4-2. 統計分布（ヒストグラム ＆ KDE密度曲線）と総合アドバイス

データを読み込むと、選んだ指標の「最小値・平均値・最大値」およびデータの分布形状がリアルタイムに描画されます。

* 📉 **ヒストグラム ＆ KDE曲線**: データのばらつきや平均・中央値の位置、左右の偏り（歪度 $\text{Skewness}$）を視覚的に把握できます。
* 💡 **作図・データ変換の判定アドバイス**:
  - **① 数値変換アドバイス**: 指標の性質（総数か割合か）や偏りに合わせて、「実測値」「100人あたり(%)」「Zスコア/偏差値」などの最適な選択を理由付きでアドバイスします。
  - **② 階級区分法アドバイス**: データの偏りやアウトライアーに応じて、「Jenks（自然分類法）」や「等間隔分類」のどちらで色分けすべきかを分かりやすく案内します。

### 4-3. 多変量データの一括選択・市町村名自動正規化

* 📊 **項目（変数）の切り替え**: 複数カラムを含むExcel/CSVを読み込んだ場合、ドロップダウンや一覧モーダルから作図する指標を瞬時に切り替えられます。
* 🪄 **市町村名の自動ゆらぎ補正**: 「青森」「あおもり」「青森市」「弘前」「弘前町（旧称）」などの表記ゆれ、全角半角、旧字体などを自動で正規化し、マッチング結果を表示します。

## 5. 画面2：マップデザイン ＆ カラーパレット設定

### 5-1. 数値の変換・統計分析モード（実測値 / 100人あたり(%) / Zスコア / 偏差値）

選択したデータを目的や分析手法に合わせて自動変換して描画できます。

* **① 実測値（そのままの数値）**: 入力データをそのままマップの色分けに使用します。
* **② 人口 100人あたり（％）の数値**: 自治体ごとの基準人口で割ってパーセント（%）化し、人口規模による偏りを補正します。
* **③ 人口 1,000人あたりの数値**: 人口1,000人あたりの指標値に換算します。
* **④ 人口 1人あたりの数値**: 1人あたりの数値に換算します。
* **⑤ Zスコア（標準化偏差 : 平均=0, SD=1）**: 全体平均からの離れ具合（標準偏差単位）に標準化して色分けします。
* **⑥ 偏差値（Tスコア : 平均=50, SD=10）**: 平均を50、標準偏差を10とした偏差値に自動変換します。

### 5-2. カラーパレット ＆ 白黒印刷向けパターン（ハッチング）

* 🔵 **単色・グラデーションパレット**: ブルー、エメラルド、パープル、Viridis、Magma、Spectral など豊富なカラーパレットを提供。
* ⚪ **白黒印刷・資料向けパターン（ハッチング）**: 白黒印刷やモノクロ論文・資料でも判別できるよう、斜線・格子・ドットなどのSVGパターン模様で塗り分けるモードを搭載。
* ⚖️ **Zスコア・偏差値専用パレット**: 平均より高い（赤・青）／平均より低い（青・赤）／平均的（白・淡色）を対照的に表現する「発散型カラー（Diverging）」を配備。Zスコア/偏差値選択時に自動セットされます。

### 5-3. 階級区分法（Jenks自然分類・等間隔・四分位等）と自動ラベル配置

* 📐 **階級区分アルゴリズム**:
  - **Jenks (自然分類法) [推奨]**: データの自然な谷間（クラスタの境界）で切り分ける最も自然な表現。
  - **Equal Interval (等間隔)**: 最小値〜最大値を等しい数値幅で分割。
  - **Quantile (等量/分位数)**: 各階級に含まれる自治体数が均等になるように分割。
* 🏷️ **ラベルの物理演算・飛び地対応**:
  - 重心計算により、市町村名ラベルを最適位置に自動配置。
  - ラベル同士の重なりを物理シミュレーション（Force-directed）で自動回避し、引出線を自動描画します。

## 7. よくある質問（FAQ）

### Q1. 「青森」や「ひろさき」と入力しても認識されますか？
**A.** はい、強力な自動正規化エンジンを搭載しているため、「市・町・村」の省略、ひらがな・カタカナ表記、ケ/ヶのゆらぎも自動補正して判定します。

### Q2. 階級数（塗り分けの区分数）はいくつか設定すればよいですか？
**A.** 青森県は40市町村のため、データ統計学および人間の視覚識別限界の視点から**「5階級」が最もバランスが良く推奨されます**。概要をシンプルに見せたい場合は3〜4階級、細かな差を分析したい場合は6〜7階級をご利用ください。

### Q3. 「人口1人あたり市町村民所得」で1,000人あたり変換を勧められますか？
**A.** いいえ。本ツールは指標名や単位に「1人あたり」「割合」「%」などが含まれている場合、すでに単位補正済みであると判別するため、二重の人口変換を誤って促すことはありません。「実測値」のままJenks分類で色分けするアドバイスが表示されます。
